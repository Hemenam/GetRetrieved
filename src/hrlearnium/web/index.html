How do I get a token?

In another terminal, from the project folder, run:

.\.venv\Scripts\python.exe -m hrlearnium token --tenant customer-demo --course captain-storm --scope query --ttl 300

Copy the printed token here. Change the tenant/course arguments for another course. Tokens expire after five minutes; generate a fresh one when needed.
